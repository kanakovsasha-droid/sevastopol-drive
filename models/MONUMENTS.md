# Памятники Севастополя для игры — список и статус

Источники: `data/poi.json` (kind=historic — оцифровка OSM), `refs/monuments.json`, `data/landmarks.json`.
В `data/osm-raw.json` и `data/chunks/*.json` тегов historic/memorial/artwork НЕТ (там только дороги и здания) —
все памятники берутся из `data/poi.json`. Рамки: x −3000…3000, z −1500…4500.
Мир: x — восток, z — юг. Координаты — из poi.json (точка OSM), для моделей уточняются по спутнику.

НЕ мои (другой агент): Приморский бульвар и площадь Нахимова — Нахимов (−5, 1), Затопленные корабли
(−88, −194), Мемориал Защитникам Севастополя и Аллея Городов-Героев (−72, 56 / x≈−67, z 80…141),
Казарский (−102, 81), Сенявин (−143, 35), Адмиралтейский якорь, Ковалевский, Миклухо-Маклай, Попов,
обелиск Черноморскому флоту (56, −203), мемориал Героям Черноморской эскадры (−273, 14) и др. рядом с бульваром.
