# cloud/wave — сборка волны облака

Собирает облачная сессия-сборщик: готовые ветки `cloud/*` с запиской в
`docs/handoff/` вливаются сюда поверх свежего `origin/hospital`. Задачи из
очереди сборщик не берёт. Метки `?v=` не штамповал: новые модули местами
импортируются без метки — `tools/stamp.mjs` при вливании это выровняет
(до штампа `env.js` грузился бы дважды, и `precip.js`/`trafficlights.js`
читали бы не тот `ENV`).

## Волна 2 (после метки hospital d8230200)

Влиты: `cloud/fuel` (доводка), `cloud/e63-atlas`, `cloud/night`,
`cloud/places`, `cloud/tails`, `cloud/wheels`. Не влита `cloud/lights` —
нет записки.

Конфликты:
- `yards.js`, `main.js` — только строки импорта: взяты метки hospital,
  добавлены новые имена (`fuelLines`, `batchCar`, `footprints.js`).
- `env.js`, `materials.js` (night против снега/дождя и света фонарей) —
  обе стороны: `uWet`, `uLamps` и `uLate`, `uTime`; в шейдере дороги сперва
  листья, потом снег с колеями и мокрый асфальт; на земле листья перед снегом.

Правка сборщика: **убран `warmCarEnv(renderer)` из `boot`** (cloud/e63-atlas).
С ним сборка чанков вставала на первом квартале: `G.chunks.built` = 0,
`building` висит, вокруг машины пустой склон (проверено бисекцией: hospital
и fuel — строится, e63-atlas сама по себе — нет; без этой строки — строится,
без `batchCar` — нет). Отражения строятся при загрузке модели, как раньше.
Склейка `batchCar` оставлена. Проверить на маке, воспроизводится ли
зависание с настоящей видеокартой (в облаке — SwiftShader).
