`docs/handoff/` вливаются сюда поверх свежего `origin/hospital`. Задачи из
очереди сборщик не берёт. Метки `?v=` не штамповал: новые модули местами
импортируются без метки — `tools/stamp.mjs` при вливании это выровняет
(до штампа `env.js` грузился бы дважды, и `precip.js`/`trafficlights.js`
читали бы не тот `ENV`).
