## Сделано: деревья на площадках памятников

- `tools/landmark-footprints.mjs` (новый): габарит каждой модели памятника
  по горизонтали из GLB (min/max POSITION с матрицами узлов; модели
  ставятся без поворота, сдвигом в `ox, oz`) → `data/landmark-footprints.json`
  (41 модель).
- `web/js/footprints.js` (новый): загрузка пятен и проверка «точка на
  памятнике» для квартала — только для моделей без контура в OSM
  (`skip` пуст); у моделей-зданий контур уже отводит посадку, а габарит
  захватил бы дворы.
- `main.js`: `loadFootprints(V)` на старте; в `buildChunk` перед
  `buildStreetProps` к `w.__noPlant` добавлено «не на памятнике» (запас
  1.2 м) — действует и на посадку по плотности, и на обмеренные деревья.

Снимки «Солдат и Матрос» (`?at=-860,120,25&look=-885,160,2`): до — шесть
деревьев на граните площадки, после — гранит чистый, деревья вокруг.
