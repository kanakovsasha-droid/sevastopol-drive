# cloud/m-w90821896 — модель «Жилой дом с оптикой, Б. Морская 27» (п. 28.33)

## Что сделано
- `models/bmorskaya27/build.py` — модель с нуля через `models/kit.py` по полю `source`
  в `refs/center-models.json`: торговый низ с витринами и тремя порталами вишнёвого камня,
  арочные двери с балконами на кронштейнах и кованой решёткой на 2-м этаже, окна в
  наличниках на 3-м, карниз, фигурный аттик на северном углу, плоская кровля с оградой
  и трубами. План — контур OSM (7 углов). Земля под углами снята из `G.terrain.heightAt`:
  улица падает к югу на 2.9 м, витрины следуют уклону; во дворе земля выше — окна
  первого этажа подняты.
- Улица по данным OSM — с ЗАПАДА (в refs написано «восток»), записано в NOTES.md.
- `data/models/bmorskaya27.glb` (10 625 тр.) и `.lod.glb` (3 611 тр.); дальний уровень
  обязателен — есть. Вызовы отрисовки: модель склеивается `batchModel` в 2–3 вызова.
- `node tools/place-models.mjs bmorskaya27` → запись в `data/landmarks.json`,
  `data/chunks/-1_1.json`, `data/chunks/far.json`; коробка OSM `w90821896` снята (skip).
- `models/bmorskaya27/NOTES.md` — что по описанию, что наугад; кадры в `out/`.

## Чужие файлы
`data/landmarks.json` (новая запись в конце), `data/chunks/-1_1.json`, `data/chunks/far.json`
(skip контура) — только скриптом `place-models.mjs`.

## Как собрано и проверено
- Blender в облаке нет: `pip install bpy` (5.2, Python 3.13) →
  `python3.13 models/bmorskaya27/build.py -- glb`; кадры — `models/render.py`, открытым
  через bpy (`bpy.ops.wm.open_mainfile` + exec render.py).
- Игра в Playwright (swiftshader): `?at=-238,1300,3&look=-216,1285,7` — дом на месте, стоит
  по уклону тротуара, ошибок в консоли нет (только 404 favicon). Снимок —
  `models/bmorskaya27/out/game_front.png`.
