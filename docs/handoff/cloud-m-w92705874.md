# cloud/m-w92705874 — Б. Морская 35 / ул. Суворова, угловой дом с лоджией (п. 28.29)

## Что сделано

- `models/bmorskaya35/build.py` — модель на `models/kit.py` по описанию из
  `refs/center-models.json` (`w92705874`): Г-образный дом по контуру OSM, три
  этажа (~12.5 м); первый этаж — гладкий светлый камень, две арки витрин на
  срезе угла и одна на Б. Морскую, остальные витрины прямоугольные; пояс;
  верх — песчаная штукатурка с горизонтальным рустом; угловая лоджия на 2–3
  этажах (по 4 ионические колонны в этаже, балюстрады, арочное окно-дверь
  внутри), сверху парапет-балюстрада с двумя шарами на тумбах; малый балкон с
  балюстрадой и окно с полуциркулем и кованым балкончиком на Б. Морскую;
  плоская кровля с решёткой и трубами. Витрины и цоколь идут по отметкам
  рельефа (улицы от угла поднимаются на 1.3–1.5 м, двор на 3 м).
- 10 611 треугольников, дальний уровень 3 525 (`data/models/bmorskaya35.glb`,
  `.lod.glb`). Атлас — общие материалы kit (`wall`, `wall2`, `trim`, …);
  `wood` перекрашен в цвет швов руста (дерева в доме нет), чтобы швы не шли в
  дальний уровень.
- `models/bmorskaya35/placement.json`, `node tools/place-models.mjs bmorskaya35`:
  запись в `data/landmarks.json`, `data/chunks/-1_1.json` (landmark + `hide`
  у `w92705874`), `data/chunks/far.json` (`hide`).
- `NOTES.md` — что взято из описания и что наугад (главное: 8/4 осей окон
  вместо «4/3» из описания — на 32 м фасада четыре окна не встают).

Чужие файлы: только данные, которые пишет `place-models.mjs` (landmarks.json,
два чанка). Код игры, `kit.py`, `render.py` не тронуты.

## Как проверить

- Кадры Blender: `models/bmorskaya35/out/corner.png` (угол с перекрёстка),
  `loggia.png` (лоджия крупно), `bmorskaya.png` (фасад на Б. Морскую),
  `top.png`, `yard.png`.
- В игре: `/web/?at=-212,1407,6&look=-172,1440,8` — снимок
  `models/bmorskaya35/out/game_corner.png`: дом стоит на углу, лоджия на
  срезе, коробка OSM снята, ошибок в консоли нет.
- Пересборка без приложения Blender: `pip install bpy` (ставится под
  Python 3.13) и `python3.13 models/bmorskaya35/build.py -- glb`.
