# cloud/m-w92717224 — Большая Морская, 3 (дом с аркадой), п. 28.6

## Что сделано
- `models/bm3/build.py` — модель с нуля через `models/kit.py` по описанию из
  `refs/center-models.json` и контуру OSM w92717224: П-образный план (крыло 63 м
  вдоль Большой Морской + два корпуса во двор), белый руст 1-го этажа, аркада из
  5 арок с витринами, кремовые 2–3-й этажи (#dfd2b3), три балкона с балясинами,
  угловые пилястры, карниз на кронштейнах, вальмовая кровля #7a7a7a.
- `data/models/bm3.glb` (9 903 треуг.) и `bm3.lod.glb` (1 957 треуг.), по
  мешу на материал (6 в ближнем, 5 в дальнем) — как у остальных моделей kit.
- `models/bm3/placement.json`, `node tools/place-models.mjs bm3`: запись в
  `data/landmarks.json` и в чанке `-1_0.json`; коробка `w92717224` скрыта
  (`hide` в `-1_0.json` и `far.json`).
- `models/bm3/NOTES.md` — что по описанию, что наугад (число арок, места
  балконов, торцы и двор).

## Тронутые чужие файлы
- `data/landmarks.json`, `data/chunks/-1_0.json`, `data/chunks/far.json` — только
  то, что пишет `tools/place-models.mjs`.

## Как собрано и проверено
- Blender в облаке нет — собрано модулем `bpy` 5.2 (pip, Python 3.13):
  `python3.13 -m venv env && env/bin/pip install bpy`, затем
  `env/bin/python models/bm3/build.py -- glb`. На маке так же:
  `blender -b --python models/bm3/build.py -- glb`.
- Кадры Blender `models/bm3/out/{front,corner,top,yard}.png` и снимки игры
  `out/game_front.png` (с Большой Морской на уровне глаз), `out/game_top.png`
  (сверху-сбоку): модель стоит на земле, с соседями не пересекается, старой
  коробки нет, ошибок в консоли нет.
- Полный `qa.mjs` не гонялся (по ROUTINE).
