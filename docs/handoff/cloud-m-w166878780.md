# cloud/m-w166878780 — модель «Жилой дом, Б. Морская 52» (п. 28.32)

## Что сделано
- `models/bm52/build.py` — дом с нуля на `models/kit.py`, план — контур OSM
  w166878780 как есть (корпус 68×13 м + крыло к ул. Шмидта). Свой примитив
  `wall_m` (стена с проёмами, куски в полосе склеены — втрое меньше
  треугольников, откосы цветом стены, чтобы дальний уровень не просвечивал),
  `win` (окно без наличника), `arch` (арочная витрина), `basement`.
- Двор по описанию: ризалит с тремя пилястрами и полкой над 3-м этажом, лестницы
  с ленточными окнами и подъездами, белые лоджии ПВХ, подвальные окна в решётках.
  Фасад на Б. Морскую не описан — арочные витрины по аналогии с БМ 33/35.
  Что наугад — `models/bm52/NOTES.md`.
- `data/models/bm52.glb` (9 499 треуг.) и `bm52.lod.glb` (4 771).
- `models/bm52/placement.json`, `node tools/place-models.mjs bm52`: запись в
  `data/landmarks.json`, `data/chunks/-1_1.json`, контур w166878780 помечен
  `hide` (в т. ч. в `data/chunks/far.json`).

## Чужие файлы
Только данные, которые пишет `tools/place-models.mjs`: `data/landmarks.json`
(+1 запись), `data/chunks/-1_1.json`, `data/chunks/far.json` (флаг hide у
w166878780). Код игры, `kit.py`, `render.py` не тронуты.

## Как проверить
- Сборка: `blender -b --python models/bm52/build.py -- glb` (в облаке —
  `pip install bpy` и `python3.13 models/bm52/build.py -- glb`).
- В игре: `/web/?at=-130,1580,4&look=-165,1605,8` (Б. Морская) и
  `/web/?at=-240,1600,45&look=-172,1608,5` (двор сверху; ждать ~60 с, пока
  приедет подробный квартал, иначе виден дальний силуэт без окон).
- Снимки (Playwright, swiftshader): дом стоит на контуре, витрины на улицу,
  двор с ризалитом и лоджиями; консоль без ошибок (кроме старого 404 ресурса).
- Вызовы отрисовки в той же точке на Б. Морской: 139 → 141 (+1,4 %),
  треугольники в пределах шума (522 → 493 тыс.).
