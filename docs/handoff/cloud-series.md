# cloud/series — типовые дома: хрущёвки, сталинки, девятиэтажки (п. 9 плана, п. 7 очереди)

Ветка `cloud/series` от `origin/hospital` (`96e9ace`). Звук не тронут.
Сборка волны (`cloud/wave`) этой задачей не делалась — по просьбе владельца.

## Что сделано

- **`tools/build-series.mjs` → `data/series.json`** (22 КБ). Серий в OSM нет
  (`building:series` нет ни у одного дома, а Overpass из облака закрыт), поэтому
  серию узнаём по тому, что лежит в чанках:
  - **девятиэтажка (p)** — 9–17 этажей ПО ТЕГУ, пятно почти прямоугольное
    (площадь ≥ 85 % рамки), глубина 10–26 м — 182 дома;
  - **хрущёвка (k)** — 4–5 этажей ПО ТЕГУ, прямоугольная пластина 9–14 м
    глубиной и ≥ 24 м длиной — 584 дома;
  - **сталинка (s)** — Центральный холм: выпуклая оболочка осевых улиц Кольца
    (пр. Нахимова — пл. Лазарева — Б. Морская — пл. Ушакова — Ленина) плюс
    45 м фронта снаружи, 3–7 этажей — 198 домов. Здесь этажность может быть и
    оценённой: меняется только фасад, высота дома прежняя.
  - Дома без тега этажности хрущёвкой/девятиэтажкой НЕ делаются (высота у них
    угадана). Памятные, раскрашенные вручную (`wc`), школы, храмы, витражи,
    нежилые типы — не трогаются.
  - Сторона подъездов — длинная стена, обращённая ОТ ближайшей улицы класса ≤ 2
    (во двор). Точек `entrance` в наших данных нет — это допущение.
- **`web/js/series.js`** (новый): грузит `series.json` (top-level await, как
  `roadlevels.js`; нет файла — всё по-старому). Даёт дому цвет серии, целое
  число пролётов на каждой стене (шаг 3.2 / 3.1 / 3.0 м чуть тянется под
  длину — окно не режется на углу), глухие торцы у пластин, на дворовой стене —
  секции по 5 (хрущёвка) / 7 (девятиэтажка) пролётов с лестничной клеткой
  посередине. Геометрия: бетонный козырёк над каждым подъездом, у девятиэтажек —
  машинное отделение лифта на кровле над лестницей. Цвет — от хеша id, общий
  генератор `rand` не трогается (кровли и цвета соседей не сдвигаются).
- **Фасады в шейдере** (`materials.js`, `buildingMaterial`):
  - вид **14 / 16** — новая ветка: ровная сетка окон (комната/кухня), окна
    лестницы в полэтажа, дверь подъезда, стояки балконов (хрущёвка: решётка /
    профлист / остеклённые, вперемешку) или лоджий (девятиэтажка), панельные
    швы (все 16 и ~половина 14) или силикатный кирпич, парапет со сливом,
    рамы белый пластик / старое дерево, ночью — свет в окнах и всю ночь на
    лестнице, фонарь над дверью. Дробная часть `aKind`: S/16 — стена подъездов,
    0.875 — глухой торец.
  - вид **15** (сталинка) идёт через общий фасад с поправками: ровный пролёт
    3.1 м, без случайных арок, лопатки через два пролёта, пояс сухариков под
    карнизом.
  - окна техподполья в цоколе — и у типовых домов.

## Тронутые чужие файлы и места

- `web/js/worldgen.js`, `buildBuildings`: импорт `series.js`; после `tint` —
  `const ser = seriesOf(b)`, цвет стены от серии; в цикле стен `u0/u1/wk` берутся
  из `seriesWall`, если дом типовой; после цикла — `seriesExtras(...)` и
  `stats.series`. Остальная логика (кровли, трубы) не менялась.
- `web/js/materials.js`, `buildingMaterial`: условие общего фасада (+вид 15),
  `stal` в нём (пролёт, арки, лопатки), новая ветка `vKind > 13.5` перед школой,
  условие окон полуподвала. Комментарий с перечнем видов.
- Новый импорт без `?v=` — метку поставит штамп.

## Как проверить

    node tools/build-series.mjs                      # пересобрать список (1 с)
    python3 tools/serve.py 5260 .
    # хрущёвка, дворовая сторона с подъездами:
    http://localhost:5260/web/?at=-566,1367,4&look=-546,1358,5&hour=13
    # 12-этажка с лоджиями и лифтовыми будками:
    http://localhost:5260/web/?at=-916,1585,12&look=-934,1545,15&hour=13
    # сталинки Центрального холма:
    http://localhost:5260/web/?at=-330,560,90&look=-150,950,0&hour=13
    # ночь:  …&hour=22

`tools/qa.mjs` в облаке не прошёл: программный рендер грузит каждое место по
3 минуты и всё равно пишет «НЕ ДОГРУЗИЛОСЬ» — надо прогнать на маке
(`--quick --base`). Шейдер собирается без ошибок, ошибок в консоли нет.

## Что осталось / допущения

- Серия по форме и этажности — догадка: кирпичная ли 1-447 или панельная
  1-464, по данным не различить; выбрано по хешу дома. Если у владельца есть
  список серий (реформа ЖКХ, «Дом.МинЖКХ»), его можно положить рядом и
  читать в `build-series.mjs` вместо формы.
- Подъезды «со двора» — допущение; где улица с обеих сторон, сторона может
  оказаться не та. Ручная правка — поменять ребро в `data/series.json`
  (или добавить список исключений в сборщик).
- Кровли хрущёвок — прежняя логика (≈92 % скатные): у 1-464 обычно плоская.
- Точечные 16-этажки, Г- и П-образные корпуса (прямоугольность < 85 %) не
  попали в серии — остаются общим фасадом.
