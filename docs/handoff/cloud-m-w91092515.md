# cloud/m-w91092515 — модель дома без адреса у пр. Нахимова (Черноморка), п. 28.13

## Что сделано
- `models/w91092515/build.py` — скрипт на `models/kit.py`. Прямоугольный корпус 46,8 × 14,1 м по контуру
  OSM w91092515, 3 этажа, стены #e0d6bd, вальма #7a7a7a (цвета и высота — из `refs/center-models.json`).
  Каменный цоколь до z = −3, тяга, карниз, 15 осей окон на длинных фасадах и 4 на торцах,
  три подъезда во двор (ЮВ) с козырьками и крыльцами, три трубы.
- `data/models/w91092515.glb` (5 914 тр.) и `.lod.glb` (1 382 тр.), `models/w91092515/w91092515.blend`.
- `models/w91092515/placement.json` + `node tools/place-models.mjs w91092515`: запись в
  `data/landmarks.json`, `data/chunks/-1_0.json`, `data/chunks/far.json`, коробка OSM снята (skip).
- `NOTES.md`: фото нет, всё, кроме плана, высоты и цветов, сделано наугад (список там).

## Тронутые чужие файлы
Только то, что пишет `tools/place-models.mjs`: `data/landmarks.json` (+1 запись),
`data/chunks/-1_0.json`, `data/chunks/far.json`. `kit.py`, `render.py`, `web/` не трогал.

## Как проверить
- Игра: `/web/?at=-426,490,5&look=-452,470,5` (двор, подъезды), `/web/?at=-495,432,8&look=-455,468,6` (с проезда).
- Снимки в игре: `models/w91092515/out/game_se.png`, `game_nw.png`; кадры Blender — `out/nw.png`,
  `out/se_air.png`, `out/se_door.png`. Модель стоит на земле, коробки OSM под ней нет, ошибок консоли нет.
- Полный `qa.mjs` не гонял (браузер без видеокарты).

## Как собрано без Blender
`python3 -m venv v && v/bin/pip install bpy` (bpy 5.0.1 под Python 3.11), `v/bin/python models/w91092515/build.py -- glb`.
Кадры — обёрткой: `bpy.ops.wm.open_mainfile(<blend>)` и `runpy.run_path('models/render.py')` с argv для render.py.
`.blend` сохранён bpy 5.0 — на маке с Blender 4.x может не открыться; тогда пересобрать `build.py`.
