# cloud/m-w90821982 — Большая Морская, 10 (п. 28.20 очереди, часть 4)

## Что сделано
- Модель углового дома Б. Морская, 10 / ул. Лумумбы (OSM `w90821982`) по
  описанию из `refs/center-models.json` и контуру OSM: `models/bm10/build.py`
  (через `models/kit.py`), `NOTES.md`, `placement.json`, кадры `out/*.png`,
  `data/models/bm10.glb` (8 977 треуг.) и `bm10.lod.glb` (2 869 треуг.).
- Фронтон 3 м на северном торце, лоджия с двумя колонками, балкон-корзина на
  консолях, окно с белой решёткой, торговый пояс (тёмно-зелёные простенки,
  кофейно-чёрные панели, кремовый козырёк), скруглённый угол со ступенями,
  карниз с дентикулами, двускатная тёмная кровля, вышка-антенна на коньке,
  ограждение кровли. Южная пристройка того же контура — сдержанно.
- Поставлена `node tools/place-models.mjs bm10`: запись в `data/landmarks.json`,
  в чанк `data/chunks/-1_0.json`, коробка OSM `w90821982` скрыта (`hide`) в
  `-1_0.json` и `far.json`.
- Blender-приложения в облаке нет — собрано модулем `bpy` 5.0.1
  (`python3.11 -m venv … && pip install bpy`; запуск
  `python models/bm10/build.py -- glb`). `kit.py` и `render.py` не тронуты.

## Чужие файлы
`data/landmarks.json` (одна запись в конце), `data/chunks/-1_0.json`,
`data/chunks/far.json` — только то, что пишет `place-models.mjs`.
