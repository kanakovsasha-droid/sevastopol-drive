## Что сделано

- `models/bmorskaya33/build.py` — дом с нуля по контуру OSM `w92707334` и
  описанию из `refs/center-models.json`: арочные витрины в светлой облицовке,
  срезанный угол с застеклённой верандой между ионическими пилястрами над
  балюстрадой, 8 осей по ул. Суворова с балконом, 2 оси на Б. Морскую,
  дворовые фасады попроще, низкие вальмы за карнизом, дымники. Три уступа по
  подъёму ул. Суворова (рельеф игры: +3 м на 47 м).
- 11 376 треугольников, дальний уровень 1 828 (GLB 550 / 98 КБ).
- `data/models/bmorskaya33.glb`, `.lod.glb`; `placement.json`;
  `node tools/place-models.mjs bmorskaya33` — запись в `data/landmarks.json`,
  в чанк `-1_1.json`, коробка `w92707334` снята (`hide` в `-1_1.json` и
  `far.json`).
- `NOTES.md` — что по описанию, что наугад (уступы, число осей, место
  балкона, двор, кровля).

Blender в облаке — модулем `bpy` 5.2 с PyPI под Python 3.13:
`uv venv -p python3.13 env && uv pip install -p env/bin/python bpy`, затем
`env/bin/python models/bmorskaya33/build.py -- glb`. Кадры — тем же модулем:
открыть `.blend` (`bpy.ops.wm.open_mainfile`) и выполнить `models/render.py`
с `sys.argv = ['', '--', <кадр>, …]`.
