# cloud/editor — редактор карты в игре (п. 39)

## Что сделано

- **F2** — режим редактора (`web/js/editor.js`, новый модуль). Включает полёт,
  отпускает мышь; панель справа. ПКМ + мышь — обзор, WASD/Space/Q — полёт.
- **Дома**: клик — выбрать (жёлтая рамка по низу и кровле). Этажность ±,
  тип (как было / хрущёвка / сталинка / девятиэтажка / частный / коробка),
  цвет стен и кровли (палитра + свой цвет), удалить / вернуть, «как было»;
  сдвиг стрелками (0,5 м, Shift — 2 м) и перетаскиванием выбранного дома,
  поворот (`[` `]`, кнопки), масштаб по длине / ширине.
- **Деревья**: выбрать кликом, удалить (Delete), сдвинуть (стрелки / мышь),
  посадить кликом выбранную породу.
- **Слой правок** — один объект, файл `data/edits.json` (пустой в репо).
  Автосохранение в localStorage `sev.edits`, кнопки «Скачать edits.json» /
  «Загрузить…» / «Взять data/edits.json» / «Сбросить всё», Ctrl+Z (200 шагов).
  На загрузке: черновик браузера, иначе файл. На сервер не пишется ничего.
- **Изменения сразу**: правка пересобирает только квадраты 1024 м, где лежит дом
  (`ChunkManager.rebuild`), старый квартал стоит на экране, пока новый не
  показан (никакой дыры). Пересобираемый квадрат качается и собирается вне
  очереди.
- Формат слоя и правила преобразования (для экспорта в Unreal) —
  `docs/EDITOR.md`.
- В «Клавишах» добавлена строка F2.

## Тронутые чужие файлы и места

- `web/js/main.js`: импорт; `boot` — `loadEdits` + `applyEditsTo(far.buildings)`
  сразу после манифеста, `chunks.onReplace`, `isBusy` паузы (+ редактор),
  создание `Editor` после `settings.quality`; `buildChunk` — `applyEdits(d)` в
  начале, `w.__treeEdit`, `registerChunk` после домов; `revealSome` и
  `dropChunk` — `dropReplaced`/`dropChunkEdits`; клик по холсту не берёт
  захват мыши, пока открыт редактор; `let editor`.
- `web/js/chunks.js`: новый метод `rebuild(key)`, приоритет `urgent` в `_buildOne`.
- `web/js/series.js` (`seriesOf`): серия из `b.edSer` (выбрана в редакторе),
  цвет стен серии из `b.edWc`. Без правок поведение то же.
- `web/js/props.js`: одна строка перед посадкой — `world.__treeEdit`.
- `web/index.html`: строка F2 в «Клавишах».
- Новые: `web/js/editor.js`, `data/edits.json`, `docs/EDITOR.md`.

## Скорость

В обычной игре: ни одного нового вызова отрисовки; на сборке квадрата — один
проход по его домам (проверка id в словаре правок). В редакторе — рамка
выбора (2 линии). Замер в headless (SwiftShader, тот же вид): 204–208 вызовов,
~0,7 млн треугольников — как без редактора (разница в пределах подгрузки).

## Как проверить

1. Открыть игру, F2. Клик по дому — рамка и панель с id и адресом.
2. «+» этажей, цвет стен — через долю секунды квартал пересобирается, дом
   выше и другого цвета; Ctrl+Z — вернуть.
3. Выбрать дом ещё раз и тащить мышью / стрелками; `[` `]` — поворот.
4. «Деревья» → «Сажать кликом» → клик по газону; выбрать дерево → Delete.
5. «Скачать edits.json», перезагрузить страницу — правки на месте (из
   localStorage); положить файл в `data/edits.json` — увидят все.

Проверено в облаке (Playwright, SwiftShader): `node --check` всех файлов,
консоль без ошибок, выбор дома по клику (Л. Толстого, 4Б, `w169280028`),
правка пишется в слой и localStorage, квадрат `-1_2` уходит в пересборку.
Снимки (`?radius=150`, вид на Л. Толстого с высоты 45 м; в git не кладу):
- до правки — башенка 4Б в 2 этажа, выбрана, рамка по низу и кровле;
- после «+4 этажа» и кирпичного цвета стен — квадрат `-1_2` пересобран, на
  месте башенки 6 этажей красно-кирпичного цвета, соседи не изменились,
  консоль чистая. Рамка оставалась на старой высоте — исправлено
  (перерисовка рамки после пересборки, эта правка снимком не проверена).
Сборка квадрата в SwiftShader — около полутора минут, на маке — доли секунды.

## Что осталось

- Скамейки и фонари не правятся (в задаче «по возможности»).
- Деревья лесов (`forest.js`) не снимаются.
- Дальний силуэт и карта видят правки только после перезагрузки.
- Дома-модели (`models/`) и навесы не выбираются.
- Посмотреть на маке живьём: плавность пересборки, перетаскивание, удобство
  панели; при желании — ещё клавиши (+/− этажей).
