# cloud/m-w166878763 — модель дома Б. Морская, 30 (п. 28.24)

## Что сделано

- `models/bm30/build.py` — модель с нуля набором `models/kit.py`: дом 1913 г. с рустованным торговым первым
  этажом, арочной нишей-лоджией на 2–3 этажах (веерная фрамуга, перила «ёлочкой», пилястры с наличниками,
  архивольт и замок), фронтоном с розеткой, правым ризалитом с карнизом, малоуклонной кровлей за парапетом.
  Дворовый фасад и брандмауэры — сдержанно, наугад.
- `data/models/bm30.glb` (6726 тр.) и `bm30.lod.glb` (1323 тр.).
- `models/bm30/placement.json` + `node tools/place-models.mjs bm30`: запись в `data/landmarks.json`, в чанке
  `-1_1.json` — landmark `lm_bm30`, контур `w166878763` помечен `hide` (в `-1_1.json` и `far.json`).
- `models/bm30/NOTES.md` — что взято из описания, что наугад; `models/bm30/out/*.png` — кадры.

## Тронутые чужие файлы

- `data/landmarks.json` — одна запись в конце; `data/chunks/-1_1.json`, `data/chunks/far.json` — их правит
  `tools/place-models.mjs` (больше ничего). Код игры не тронут.

## Как проверить

- `python models/bm30/build.py -- glb` (в облаке — `pip install bpy` в venv на Python 3.13) — пересборка.
- В игре: `/web/?at=-269.8,1157.9,5&look=-282.7,1156.1,7` — уличный фасад; снимок `models/bm30/out/game_front.png`
  (headless, чанк догружается ~2 мин). Ошибок в консоли нет, вызовов отрисовки на кадр ~200.
