# cloud/wheels — колёса и асфальт (п. 6 очереди) — ЗАМЕР, без правки физики

От `origin/hospital` (fcf3f02). Кода игры ветка не меняет — только инструмент
замера и выводы: правка нужна в сборке дорог (`buildRoads`), которую по
`NIGHT.md` трогать нельзя без хозяина.

## Инструмент

`tools/check-asphalt.mjs <порт> [радиус]` — по осевым и краям полос
(1.2 м от кромки) всех улиц c ≤ 3 без мостов/тоннелей в радиусе от старта
(−398, 484) сравнивает высоту НАРИСОВАННОГО полотна (`RoadSurface.heightAt`,
по треугольникам сцены) с профилем физики (`driveHeightAt + 0.145`).

## Почему не правил физику

Пробовал расширить полосу доверия вниз (−0.3 → −0.8 м) — без эффекта: в
`_step` поправка до асфальта нарочно «только вверх» (`clamp(_sOff, 0,
0.12)`) — чтобы колесо не ныряло в узкий проезд поперёк широкой улицы. Это
решение хозяина физики, и оно верное для того случая. Значит, чинить само
полотно: в перечисленных местах (дворовые проезды у стенок площадок домов и
стык у (−44, 800)) полотно опущено на 30–66 см ниже профиля коридора —
`buildRoads` (поправка провисания/площадки домов) или `driveHeightAt` (профиль
не знает о площадке). Обратный случай (+5…+45 см, 829 точек) колесо гасит
потолком 12 см — там колесо утопает в асфальт до ~30 см.
