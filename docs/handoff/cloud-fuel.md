# cloud/fuel — заправки АТАН, ТЭС и другие сети (п. 4 очереди CLOUD.md)

От `origin/hospital` (7c44b72), в ветку влит свежий `origin/hospital` (96e9ace).
Две сессии: первая — d993790, вторая — доводка (коммиты после 92c51a7).

## Что сделано

- `web/js/fuel.js` (новый): сеть АЗС по имени из OSM (`world.fuel[].n`), а
  если по имени не узнали — по тегу `brand` (`world.fuel[].b`). Имя важнее:
  `brand` в OSM нередко остался от прежнего хозяина («Атан» с brand=ТНК).
  Написания сводятся к сети: «Атан», «ATAN Россия №84», «АТАН» → АТАН;
  «TES», «Tes», «ТES», «ТЭС», «Тэс» → ТЭС; плюс СНП, ТНК, WOG, Татнефть,
  CRS, Баррель, Formula, RS; газовые (пропан, метан, АГЗС, АГНКС) → ГАЗ.
  Неузнанное короткое имя — как в OSM («Авто Стоп», «Мерксия»), без имени —
  без подписи.
- Подписи: имя сети на фризе навеса с обеих длинных сторон и на щите стелы.
- Виды топлива на стеле — **только из данных**: теги `fuel:*=yes`
  (`world.fuel[].fu`), или по имени газовой («АГНКС СНП», «Газ Метан» →
  МЕТАН; «Пропан», «АГЗС» → ПРОПАН). Не знаем — три пустые строки табло, как
  было до задачи (раньше в ветке всем писалось «АИ-92 / АИ-95 / ДТ», а
  АГНКС — «ПРОПАН»; это выдумка, убрано). Цен нет: брать неоткуда.
- Атлас вывесок: ячейка в пропорциях щита (раньше все ячейки 512×128, и
  надпись на почти квадратной стеле была сплющена по ширине в ~5 раз, а на
  фризе растянута в ~3 раза). Две стороны одного щита делят одну ячейку;
  холст не выше 8192 px. Все надписи квартала — одна сетка (+1 вызов
  отрисовки на квартал, где есть АЗС).
- Столб стелы теперь до низа щита: он толще щита и проступал сквозь надписи.
- `tools/fetch-areas.mjs`, `tools/build-world.mjs`: `brand` и `fuel:*`
  доезжают до `world.fuel` (`b`, `fu`). **`data/world.json` не
  пересобирал**: из облака Overpass закрыт, а в репозитории `world.json`
  собран версией, которой нет в `tools/` (у АЗС есть поле `id: "fu@…"`, его
  `build-world.mjs` не пишет). Пока `b`/`fu` в данных нет, код работает по
  имени; после пересборки на маке подхватит сам.

## ВАЖНО: цвета сетей не заполнены

Из облака фирменные цвета сверить не с чем: Викисклад, Викиданные, Overpass
и сайты сетей закрыты сетью сессии, а правило — не выдумывать. В поиске
нашлось только форумное «жёлтенькие» про АЗС АТАН — это не основание для
цвета. Поэтому у всех сетей `col: null`, и АЗС в прежних зелёных цветах.
Нужно (локальная сессия, по панорамам Яндекса): заполнить в `BRANDS`
`col: { band, board, text }` (sRGB 0..1) хотя бы у АТАН и ТЭС — подзор,
верх колонок, парапет кассы, щит стелы и надписи перекрасятся сами.

  Google Fonts.
