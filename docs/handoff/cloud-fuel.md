# cloud/fuel — заправки АТАН, ТЭС и другие сети (п. 4 очереди CLOUD.md)

От `origin/hospital` (7c44b72).

## Что сделано

- `web/js/fuel.js` (новый): сеть АЗС по имени из OSM (`world.fuel[].n`).
  Написания в данных разные — сводятся к сети: «Атан», «ATAN Россия №84»,
  «АТАН» → АТАН; «TES», «Tes», «ТES», «ТЭС», «Тэс» → ТЭС; плюс СНП, ТНК, WOG,
  Татнефть, CRS, Баррель, Formula, RS; газовые (пропан, метан, АГЗС, АГНКС).
  Неузнанное короткое имя пишется как в OSM («Авто Стоп», «Мерксия»),
  без имени — без подписи.
- Подписи: имя сети на фризе навеса с обеих длинных сторон и на щите стелы,
  под ним виды топлива («АИ-92 / АИ-95 / ДТ» или «ПРОПАН»). Цен нет: брать
  неоткуда. Все надписи квартала — один атлас и одна сетка (+1 вызов
  отрисовки на квартал с АЗС).
- Цвета навеса, колонок, кассы и стелы берутся из таблицы сетей
  `BRANDS[].col` в `fuel.js`.

## ВАЖНО: цвета сетей не заполнены

Из облака фирменные цвета сверить не с чем: Викисклад, сайты сетей и
панорамы закрыты сетью сессии, а правило — не выдумывать. Поэтому у всех
сетей `col: null`, и АЗС пока в прежних зелёных цветах. Нужно (локальная
сессия, по панорамам Яндекса): заполнить `col: { band, board, text }`
(sRGB 0..1) хотя бы у АТАН и ТЭС — больше ничего менять не надо.
