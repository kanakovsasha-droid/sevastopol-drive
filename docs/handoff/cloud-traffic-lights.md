# cloud/traffic-lights — светофоры (п. 5 плана, п. 3 очереди)

От `origin/hospital` (7c44b72).

## Что сделано

- `web/js/trafficlights.js` (новый): модель как в Севастополе — серая стойка
  3.9 м, транспортная головка Т.1 на кронштейне: жёлтый корпус, три секции
  с козырьками, чёрный экран. Лицом (+z) — навстречу своей полосе.
- Цикл огней: зелёный 20 с → мигающий зелёный 3 с → жёлтый 3 с → красный
  23 с (последние 2 с — красный с жёлтым). Направления «вдоль» и «поперёк»
  (по углу головки) в противофазе; у перекрёстков — свой сдвиг по клетке
  60 м. Огни считает шейдер по `ENV.uTime` (на паузе стоит), ночью ярче
  (`ENV.uNight`). Фаза — в `instanceColor.r`, геометрия и материал общие:
  один вызов отрисовки на квартал, как и было.
- Расстановка (`furniture.js`): точка OSM `highway=traffic_signals` лежит на
  осевой — теперь столб у бордюра с КАЖДОЙ стороны дороги, на односторонней
  (`ow`) — только справа по ходу потока. Дубли одного перекрёстка (головка в
  7 м, смотрящая туда же) отбрасываются. Старая модель на консоли из
  `furniture.js` убрана.

Все светофоры города — это 83 узла OSM (`data/furniture.json`), других
данных нет; в центре их немного (у старта ближайший — 128 м, на (−472, 588)).

## Тронутые чужие файлы

- `furniture.js` — импорт `buildTrafficLights`; у `snapToKerb` необязательный
  параметр `only` (только эта сторона); блок светофоров вместо
  `put('светофоры', …)`; удалена `trafficGeo()`.

## Как проверить

- `?at=-440,560,4&look=-467,591,2` — светофор у старта: корпус жёлтый,
  через ~20 с зелёный мигает, жёлтый, красный.
- `?hour=22` — огни ярче ночью.

## Что осталось

- Головки над проезжей частью на консоли для широких улиц (раньше была одна
  консоль на всё) — можно добавить второй тип для `w ≥ 12`.
- Пешеходные секции не ставились (в OSM нет признака, где они есть).
- Фазы перекрёстка по клетке 60 м: перекрёсток на границе клеток может
  получить два сдвига.
