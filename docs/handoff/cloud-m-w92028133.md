# cloud/m-w92028133 — модель «Нахимова 12» (очередь, часть 4, п. 28.9)

## Что сделано
- `models/nahimova12/build.py` — модель с нуля через `models/kit.py`: трёхэтажный
  дом из кремового известняка по контуру OSM `w92028133`, план выпрямлен до буквы Г
  (корпус 35.4 × 14.1 м вдоль пр. Нахимова + крыло 13.8 × 20.6 м у ул. Маяковского).
  Уличные фасады: арочные окна и руст первого этажа, пояса, окна с наличниками,
  угловые рустованные лопатки, карниз; двор — простые окна и три подъезда; вальмовые
  серые кровли, трубы, водостоки.
- 8 626 треугольников, дальний уровень 1 782 (в коридоре 5–10 тыс.). GLB:
  `data/models/nahimova12.glb` (457 КБ) и `.lod.glb` (94 КБ).
- `models/nahimova12/placement.json`, `node tools/place-models.mjs nahimova12`:
  запись в `data/landmarks.json`, в чанке `-1_0.json` (и `far.json`) коробка
  `w92028133` помечена `hide`.
- `models/nahimova12/NOTES.md` — источники и что наугад (почти всё, кроме плана и
  числа этажей: фото в записи нет).

## Тронутые чужие файлы
- `data/landmarks.json` (+1 запись в конце), `data/chunks/-1_0.json`,
  `data/chunks/far.json` — только через `tools/place-models.mjs`.
- Код игры (`web/`), `kit.py`, `render.py` не трогал.

## Как проверить
- Снимок в игре: `models/nahimova12/out/game_front.png`
  (`/web/?at=-398,520,3&look=-426,498,7`) — дом на месте коробки, стоит на земле,
  кровля не протыкает соседей, консоль без ошибок.
- Кадры Blender: `out/front.png`, `out/corner.png`, `out/yard.png`, `out/top.png`.
- Пересборка: Blender в облаке нет, собрано модулем `bpy` 5.2.2 из pip
  (`uv venv -p 3.13; uv pip install bpy`) — `python models/nahimova12/build.py -- glb`.
  На маке как обычно: `blender -b --python models/nahimova12/build.py -- glb`.

## Замечания

  а 21.6 м смотрит во двор. Сделано по дорогам.
