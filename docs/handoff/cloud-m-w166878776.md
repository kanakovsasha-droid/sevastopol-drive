# cloud/m-w166878776 — Центральный шахматный клуб, Б. Морская, 50 (очередь, п. 28.28)

## Что сделано

Модель здания `w166878776` скриптом Blender по образцу `models/sevgu_gogolya14`:
`models/shahmat_klub/build.py` (набор `models/kit.py`, не правился), два уровня
`data/models/shahmat_klub.glb` (9 324 треугольника) и `.lod.glb` (2 180), `.blend`,
кадры `models/shahmat_klub/out/*.png`, `NOTES.md` (что по описанию, что наугад),
`placement.json`. Поставлена `node tools/place-models.mjs shahmat_klub`: запись в
`data/landmarks.json`, `data/chunks/-1_1.json`, коробка OSM `w166878776` снята
(`hide`) в `-1_1.json` и `far.json`.

- План — контур OSM: в системе, повёрнутой на ~15°, он ровно раскладывается на
  семь прямоугольников (два крыла по 42 м, средний корпус, связки, выступ к улице,
  торец), стены режутся по открытым участкам сторон автоматически
  (`open_spans`), так что лишних стен внутри нет.
- Полуротонда по описанию `refs/center-models.json`: 5 веерных ступеней по дуге
  контура (r 6.1), подиум, 8 гладких колонн парами без капителей со швами
  барабанов, антаблемент, полукруглый балкон с балюстрадой и тумбами, по оси
  тёмная дверь, барельеф со звездой и окно; выше барабан с 7 короткими
  колоннами и 6 арочными окнами, карниз, пологий купол. Простенки по бокам — с
  консолями под карнизом. Цвета — из описания (#ebe2c8, #efe8d4, кровля #8d8f8a).
- Корпуса — три этажа, окна по шагу 3.4 м, пояс, карниз, парапет, плоская кровля
  (наугад, задние корпуса на фото не видны; см. NOTES.md).

Bpy в облаке: `pip install bpy` (5.2) и обёртка `blender` на python — скрипты
`build.py`/`render.py` идут без изменений.
