# cloud/m-w90821942 — модель «Большая Морская, 20» (пункт 28.26)

## Что сделано
- `models/bm20/build.py` — модель трёхэтажного жилого дома с рустованным низом
  и магазинами по описанию из `refs/center-models.json` (фото в облаке
  недоступно — работа только по тексту `source`). План — контур OSM
  w90821942 (40.1 × 13.3 м + пристройка во двор 13.3 × 3.5 м).
  Рустованный низ 4.2 м с витринами, вход справа по ступеням с балюстрадой,
  9 осей, парные арочные окна на осях 2 и 8, три балкона с решётками,
  эркер на консолях с балконом сверху (слева), карниз с дентикулами,
  плоская кровля с парапетом, трубы.
- 9 920 треугольников, дальний уровень 1 462 (бюджет 5–10 тыс.).
- `data/models/bm20.glb`, `bm20.lod.glb`; `models/bm20/placement.json`;
  `node tools/place-models.mjs bm20` — запись в `data/landmarks.json`,
  чанк `-1_1`, контур w90821942 помечен `hide` в `-1_0`, `-1_1`, `far`.
- `models/bm20/NOTES.md` — что по описанию и что наугад.
- Кадры Blender: `models/bm20/out/front.png`, `erker.png`, `steps.png`,
  `north.png`, `yard.png`, `air.png`; в игре — `out/game_front.png`
  (с Б. Морской: дом стоит на месте старой коробки, посадка по рельефу верная,
  низ не висит и не тонет).

## Тронутые чужие файлы
- `data/landmarks.json` (+1 запись), `data/chunks/-1_0.json`, `-1_1.json`,
  `far.json` — только скриптом `tools/place-models.mjs`. При конфликте с
  другими ветками 28.x: взять их версию и заново прогнать
  `node tools/place-models.mjs bm20`.
- Код игры не тронут.

## Как проверить
`/web/?at=-275,1062,7&look=-313,1040,8` — фасад с Б. Морской.
Пересборка: `blender -b --python models/bm20/build.py -- glb` (в облаке —
`python3.13 models/bm20/build.py -- glb` с `pip install bpy`).
