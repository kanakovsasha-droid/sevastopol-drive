# cloud/map-touch — карта на маке (п. 17 очереди, часть 2)

## Что сделано

Новый модуль `web/js/mapnav.js` (класс `MapNav`) — управление полноэкранной картой (Tab):

- **щипок тачпада** (wheel с `ctrlKey`) — плавный масштаб вокруг точки под курсором;
  в Safari щипок приходит `gesturechange` — тоже обработан (если тот же щипок уже пришёл
  ctrl-колесом, жест пропускается, чтобы масштаб не удвоился);
- **два пальца по тачпаду** (wheel без ctrl, с дробными шагами / deltaX) — сдвиг карты;
- **колесо мыши** (wheelDeltaY = −3·deltaY, шаг 120) — масштаб ступенькой ×1.25 / ×0.8, вокруг курсора;
- **перетаскивание** мышью / пальцем — сдвиг; два пальца на сенсорном экране — щипок + сдвиг;
- **кнопки** справа: `+`, `−`, `⌖` (вернуть центр на игрока); клавиши `=` / `−` (и Numpad +/−);
- **клик «переехать» не сломан**: обычный клик по-прежнему `mapClick`; клик, завершивший
  перетаскивание (> 5 px), глушится в фазе захвата на `#mapfull`.
- Подсказка внизу карты переписана в одну строку.

На общем плане (zoom = 1, весь мир) сдвиг не действует — карта вписана целиком, как раньше.
При каждом открытии карта снова по центру игрока в масштабе ~7 км на экран.

## Тронутые чужие файлы

- `web/js/minimap.js` — `drawFull(…, zoom, center = null)`: новый необязательный параметр
  центра в метрах; без него поведение прежнее.
- `web/js/main.js`:
  - импорт `MapNav` (без `?v=` — метку поставит штамп);
  - `let mapZoom` → `let mapNav`;
  - в глобальном `wheel`: при открытой карте только `preventDefault` (колесо обрабатывает mapnav);
  - после `$('mapcv').addEventListener('click', mapClick)` — создание `mapNav`;
  - `toggleMap()`: `mapNav.reset(…)` вместо присваивания `mapZoom`;
  - `drawMap()`: позиция игрока через новую `playerPos()`, в `drawFull` передаются
    `mapNav.zoom`, `mapNav.center()`.

Скорость: кадр игры не затронут (карта рисуется только когда открыта, как и раньше).

## Как проверить

1. Открыть игру, Tab.
2. На маке: щипок тачпада — масштаб у курсора; два пальца — карта едет; кнопки +/−/⌖.
3. Перетащить карту мышью и отпустить — карта остаётся открытой; простой клик — переезд.

Проверено в облаке (Playwright, Chromium без GPU): синтетические ctrl-wheel (масштаб),
wheel с дробными deltaX/deltaY (сдвиг, игрок уехал из центра), перетаскивание мышью
(карта не закрылась), кнопки, клик (переезд, карта закрылась). В консоли ошибок нет, кроме
недоступного в облаке Google Fonts (сеть песочницы). `node --check` трёх файлов — чисто.

## Что осталось

- Живая проверка на маке: определение «тачпад или колесо» эвристическое (`isTrackpad`);
  если у владельца мышь со свободным колесом даёт дробные шаги, она начнёт сдвигать,
  а не масштабировать — тогда подстроить порог там же.
- Нативные жесты Safari на реальном тачпаде не проверены (в облаке только Chromium).
