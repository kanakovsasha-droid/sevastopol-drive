# cloud/m-w95119639 — модель дома Б. Морская, 2 («Черноморочка»)

Пункт 28.2 очереди, часть 4.

## Что сделано
- `models/bmorskaya2/build.py` — модель с нуля на `models/kit.py` по описанию
  из `refs/center-models.json` (фото недоступны, см. NOTES.md): арочные
  витрины 1 этажа в известняке с рустом, вход с четырьмя створками по центру,
  сплошной карниз-балкон с балюстрадой, окна 2–3 этажей (сандрики / арочные с
  балкончиками), пилястры, карниз на кронштейнах, глухие торцы, простой
  дворовый фасад, плоская кровля.
- 9 477 треугольников, дальний уровень 2 447 (бюджет 5–10 тыс.). GLB:
  `data/models/bmorskaya2.glb` (505 КБ), `.lod.glb` (132 КБ).
- `models/bmorskaya2/placement.json` → `node tools/place-models.mjs bmorskaya2`:
  запись в `data/landmarks.json`, в чанке `data/chunks/-1_0.json` и пометка
  `hide` контура w95119639 (в `-1_0.json` и `far.json`).
- `NOTES.md` — что взято из описания и что наугад; кадры в `models/bmorskaya2/out/`.

## Чужие файлы
- `data/landmarks.json`, `data/chunks/-1_0.json`, `data/chunks/far.json` —
  только то, что пишет `tools/place-models.mjs`.
- Код игры не тронут.

## Как проверить
- `/web/?at=-398,600,3&look=-428,622,7` — подробный уровень подгружается
  ближе 380 м (в headless — ~1 мин); снимок `models/bmorskaya2/out/game_front.png`:
  модель стоит по контуру, от коробки OSM ничего не осталось, ошибок в консоли нет.
- Пересборка: `blender -b --python models/bmorskaya2/build.py -- glb` (в облаке
  собиралось модулем bpy 5.2: `python3.13 models/bmorskaya2/build.py -- glb`).
