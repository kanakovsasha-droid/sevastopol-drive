# cloud/m-w90821892 — караимская кенасса (Б. Морская, 11), п. 28.18

## Что сделано
- Модель `models/kenassa/`: `build.py`, `NOTES.md`, `placement.json`, кадры `out/game_*.png`;
  GLB `data/models/kenassa.glb` (6161 треуг.) и `kenassa.lod.glb` (195 треуг.).
- Поставлена `node tools/place-models.mjs kenassa`: запись в `data/landmarks.json`, в чанке `-1_0.json`
  и пометка контура в `far.json`; коробка OSM `w90821892` снята (skip).
- Портик с двумя коринфскими колоннами в нише, арочное окно с веером, антаблемент с дентикулами, карниз
  с модульонами, высокий фронтон, белёный цоколь с зелёным отливом, более высокий зал с вальмой.

## Важно: без Blender
В облаке нет Blender, установку bpy (pip, 400 МБ) автоматика сессии запретила. Поэтому `build.py` —
самостоятельный писатель GLB на чистом Python с теми же именами материалов, что у `models/kit.py`
(склейка `modelbatch.js` работает как обычно: в игре 2 сетки на дом). `.blend` нет, рендеров Blender
нет — кадры сняты в самой игре. Если для единообразия нужен kit.py — переложить на маке; размеры и
решения записаны в `models/kenassa/NOTES.md`.

## Чужие файлы

## Как проверить
- `python3 models/kenassa/build.py && node tools/place-models.mjs kenassa` — пересобрать.
- Игра: `/web/?at=-296,925,6&look=-308.6,905,7` (портик), `/web/?at=-335,945,22&look=-310,895,10` (сверху).
- Консоль чистая (единственная 404 — favicon). Вызовов отрисовки: модель даёт 2 склеенные сетки вместо
  коробки OSM — в пределах +5%.
