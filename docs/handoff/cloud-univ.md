# cloud/univ — учебные заведения центра: СевГУ и институты (только по OSM)

Ветка `cloud/univ` от `origin/hospital` (`7023712`). Сборку волны не делал.

## Почему «только по OSM»

Из облака закрыт весь внешний интернет: commons.wikimedia.org,
upload.wikimedia.org, ru.wikipedia.org, Яндекс, спутник ESRI, Overpass/OSM
(прокси отвечает 403). Фото Викисклада не посмотреть. Владелец выбрал
вариант «только по OSM, фасады по фото — потом на маке». Поэтому цветов,
вывесок и входов, которых нет в данных, здесь нет.

## Что оказалось уже сделано до этой ветки

- Всё, по чему разбор фото лежит в `refs/`, в игре уже стоит:
  - корпус СевГУ на Гоголя, 14 (`w111424195`): `houses.json` и модель
    `rotundaOrder` в `landmarks.json` — ротонда, парные тосканские колонны;
  - ИнБЮМ (`w104316994`) и МГИ (`w104711079`): `houses.json` — цвет, высота,
    кровля, у ИнБЮМ вывеска «АКВАРИУМ»;
  - Дом Москвы — модель.
- Остальные три записи `refs/institutes.json` — не учебные заведения:
  - Штаб ЧФ: уже модель, а по OSM разрушен 22.09.2023;
  - Архив ЧФ и УМВД: в справке уверенность «низкая», фасадов нет. Их не
    трогал.
- Все дома с `building=university` / `college` в OSM (21 шт.) сборщик
  (`tools/build-world.mjs`, блок «школы») уже рисует учебным фасадом (вид 12:
  ленты окон, лестничный витраж) с плоской кровлей. Этажность — из тегов OSM
  (`building:levels`), без тега — 3 этажа. Это и есть вариант «только по OSM»:
  без цвета и вывесок, кроме имени из OSM.

   `w93168382` действительно спортядро. Если да — можно нарисовать дорожку и
