# Редактор карты (F2)

Правка города прямо в игре, без Blender и без пересборки данных. Модуль —
`web/js/editor.js`, врезка — `main.js` (`buildChunk`, `dropChunk`,
`revealSome`, загрузка), пересборка квадрата — `ChunkManager.rebuild`
(`chunks.js`).

## Как пользоваться

- **F2** — открыть / закрыть (или Esc, если ничего не выбрано). Игра
  переходит в полёт: WASD, Space / Q — вверх-вниз, колесо — скорость,
  **правая кнопка + мышь** — обзор.
- **Дома**: клик по дому — выбрать (жёлтая рамка). Панель: этажность (±),
  тип (как было / хрущёвка / сталинка / девятиэтажка / частный / коробка),
  цвет стен и кровли (палитра или свой цвет), поворот, длина и ширина
  контура, удалить / вернуть, «как было».
  Сдвиг — стрелки (по 0,5 м, с Shift — по 2 м, «вверх» — от камеры) или
  перетащить уже выбранный дом мышью. `[` / `]` — поворот на 2° (Shift — 15°).
  Delete — удалить / вернуть.
- **Деревья**: клик по дереву — выбрать; Delete — убрать; стрелки или мышь —
  сдвинуть. «Сажать кликом» + порода — клик по земле сажает дерево.
- **Ctrl+Z** — отмена (до 200 шагов).
- Изменения видны сразу: пересобираются только квадраты 1024 м, где лежит
  дом (дерево); старый квартал стоит на экране, пока новый не готов.
- Правки сами сохраняются в браузере (localStorage `sev.edits`).
  **«Скачать edits.json»** — файл; положить его в `data/edits.json` и
  выложить — тогда правки увидят все. **«Загрузить…»** — взять файл с диска.
  «Взять data/edits.json» — заменить черновик браузера файлом с сайта.
  На сервер редактор ничего не пишет.

Порядок при загрузке игры: черновик из localStorage, а если его нет —
`data/edits.json`.

## Формат `data/edits.json`

```json
{
  "version": 1,
  "buildings": {
    "w169280028": { "lv": 5, "ser": "k", "wc": "#e8c9a3", "rc": "#5e544c",
                    "dx": 1.5, "dz": -0.5, "rot": 4, "len": 1.1, "wid": 0.95 },
    "w93168291":  { "del": true }
  },
  "trees": {
    "add": [ { "uid": "tm3x1a2b", "x": -870.5, "z": 2160.2, "k": "platan", "w": 0.9, "h": 0.9 } ],
    "del": [ [-861.3, 2149.8] ]
  }
}
```

Дома — по id OSM (`w…` / `r…:N`, как в `data/world.json` и чанках). Все поля
необязательные; отсутствующее поле — «как в данных».

| поле | что | как применяется |
|---|---|---|
| `lv` | этажей | высота `lv·3.2 + 1.2` м (как `parseH` в `tools/build-world.mjs`) |
| `ser` | `k` хрущёвка, `s` сталинка, `p` девятиэтажка, `house` частный, `box` коробка | `k/s/p` — своя запись серии на доме (`edSer`, `series.js`; подъезды по длинной стене; без `lv` — 5 / 4 / 9 этажей); `house` — вальма, 2 этажа; `box` — плоская кровля без серии |
| `wc`, `rc` | цвет стен, кровли `#rrggbb` | поверх палитры (`palette.js`, у серий — `series.js`) |
| `dx`, `dz` | сдвиг, м (x — восток, z — юг) | после поворота и масштаба |
| `rot` | поворот, градусы | вокруг центра исходного контура |
| `len`, `wid` | масштаб вдоль / поперёк длинной стены исходного контура | 1 = как было |
| `del` | удалить | дом выбрасывается из данных квадрата и дальнего слоя |

Порядок преобразования контура: масштаб по осям дома → поворот → сдвиг, всё
от исходного контура OSM (дворы-`holes` и арка `gate` едут вместе с ним).

Деревья: `add` — новые (порода `k` из `TREES` в `flora.js`: platan, chestnut,
acacia, poplar, pine, olive, cypress, thuja, spruce; `w`, `h` — масштаб кроны
и высоты, 1 ≈ 11 м); `del` — точки `[x, z]`: снимается любое дерево ближе
1,6 м по каждой оси. Перенос своего (не посаженного руками) дерева = `del`
старой точки + `add` новой той же породы и размера.

## Для экспорта в Unreal

Слой — чистые данные поверх OSM: экспортёр берёт контуры из `data/world.json`
и применяет к ним те же правила (функция `applyOne` в `editor.js` —
эталон: масштаб → поворот → сдвиг от центра исходного контура, высота из
`lv`). Деревья — точки с породой и масштабом. Ничего, кроме этого файла,
редактор не меняет.

## Чего нет (пока)

- Скамейки и фонари не правятся (только дома и деревья).
- Деревья лесных массивов (`forest.js`) снять нельзя — только городские
  посадки и обмеренные.
- Дальний силуэт и карта берут правки только при загрузке игры (после
  перезагрузки страницы), не на лету.
- Дома-модели (памятные здания из `models/`) не выбираются — у них своя
  разметка (`placement.json`).
