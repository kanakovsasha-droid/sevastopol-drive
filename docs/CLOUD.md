# Работа облачной сессии (Claude Code в вебе)

Облачная сессия — основной исполнитель. Локальная сессия на маке только
проверяет, вливает в `main` и делает то, чего в облаке не сделать
(панорамы Яндекса, прослушивание звука, Blender, если его не поставить).

## Ветки

- Свежая сборка — ветка **`hospital`** на GitHub. Каждую задачу начинай от
  неё: `git fetch origin && git checkout -b cloud/<коротко> origin/hospital`.
- Пушь только свои ветки `cloud/*`. **В `main` не пушить**: пуш в `main` =
  выкладка на сайт; вливает локальная сессия после проверки.
- Одна задача = одна ветка = отдельная записка `docs/handoff/<ветка>.md`
  (что сделано, тронутые чужие файлы и места, как проверить, что осталось) —
  по образцу `docs/HANDOFF.md`.
- `tools/stamp.mjs` не запускать (метки ставит тот, кто вливает). Если всё же
  поменялись `?v=` в импортах — не коммитить эти строки.
- Длинную задачу коммить кусками и пушь по ходу — сессия может оборваться.
- **Сборка волны — твоя.** Готовые задачи сливай сам в ветку `cloud/wave`
  (от свежего `origin/hospital`), конфликты разрешай сам, проверяй, что всё
  вместе запускается (консоль без ошибок, `tools/qa.mjs --quick`), и пушь.
  Локальная сессия вливает только `cloud/wave` — без конфликтов. Строки `?v=`
  в импортах при конфликте бери любые, метки перебьёт штамп.
- Перед каждой новой задачей и перед сборкой волны — `git fetch` и
  `git merge origin/hospital`: туда приходят правки звука и дорог с мака.

## Правила проекта

- Прочитай `README.md`, `docs/NIGHT.md` (устройство, хозяева файлов,
  снимки), `docs/PLAN.md` (весь план). Коммиты и комментарии — на русском, в
  стиле окружающего кода.
- Новое — новым модулем в `web/js/` с минимальной врезкой в `main.js`.
- Звук не трогать (`engine-audio.js`, `carfx.js`, `data/audio/`) — его
  слушает владелец, правки только по его отзыву.
- Ничего не выдумывать про город: только OSM, Викисклад, открытые данные.
  Нет данных — не ставить («лучше пусто, чем криво»).
- Чужие ассеты — только CC0 / CC BY с записью в ATTRIBUTION.
- Скорость: не больше +5% вызовов отрисовки и треугольников на задачу без
  причины. Мерить `G.info`.

## Проверка перед сдачей

- `node tools/qa.mjs --port <порт> --quick --base <прогон до>` — автопроверка
  (кадры, профили дорог, заезды машины); полный прогон без `--quick`.
  Подробно — в шапке `tools/qa.mjs`. Если в облаке нет браузера для
  Playwright — поставь (`npx playwright install chromium`).
- Снимки своих мест «до/после» (`tools/shot.mjs`), каждый открыть и
  посмотреть. В записке — что видно на снимках.

## Очередь задач (сверху вниз, бери следующую свободную)

1. **Пауза** (п. 15 плана): Esc / Options — меню паузы, мир и физика
   замирают, звук глушится через master gain (сам звук не менять); пункты:
   продолжить, гараж, места, настройки (`settings.js`), клавиши.
2. **Режимы езды Eco / Comfort / Sport / Sport+** (п. 13): отклик газа,
   точки переключения, руль, ESP — параметрами поверх `vehicle.js`, значок
   на приборе (`hud.js`). Громкость выхлопа — только множителем.
3. **Светофоры** (п. 5): все светофоры из OSM в центре, модель как в
   Севастополе (жёлтый корпус, три секции), повёрнуты к своей полосе, работают
   циклом; ночью светятся (`ENV.uNight`).
4. **Заправки АТАН и ТЭС**: из `data/world.json` `fuel` — навес, колонки,
   стела с ценами в цветах сети; бренд — из тега OSM `brand/name`.
5. **Хвосты из PLAN.md**: деревья на площадках памятников; песчаный мыс у
   Затопленных кораблей; дыра у парома / студгородка; «бесконечный столб» на
   карте; трамплины в данных дорог у (327, 1235) и (192, 1101).
6. **Колёса и асфальт**: оставшиеся 44 места, где физика не встаёт на
   асфальт (дворовые проезды у стенок площадок домов) — см. отчёт в
   `docs/handoff/roads3.md`, если он есть, иначе мерить по
   `driveHeightAt` против нарисованного полотна.
7. **Типовые дома** (п. 9): хрущёвки, сталинки, девятиэтажки клонами по
   контурам OSM (этажность из тегов), без ухудшения скорости.
8. **Гостиница «Севастополь»**: крыша под надписью протыкает соседний объём;
   сквер между театром Луначарского и гостиницей (контуры из OSM).
9. **Артбухта**: скейт-парк у «Челентано» (контур и элементы — по OSM и
   Викискладу).
10. **Учебные заведения** (п. 14): школы центра — типовыми проектами по
    контурам; список — `refs/institutes.json`.
11. **Ночь и сезоны — доводка**: светящиеся окна по домам вразнобой, листва
    на тротуарах осенью; проверить скорость ночью.
12. **Атлас материалов для E63** (−90 вызовов отрисовки), асинхронный PMREM.

## Очередь, часть 3 (с 05.10.2026 вечер) — бери сверху свободную, ветка `cloud/<имя>` в скобках

19. **Остановки транспорта** (`cloud/stops`): все `highway=bus_stop` / `public_transport=platform` из данных —
    павильон с навесом и скамейкой у бордюра своей полосы, табличка с названием из OSM; без наложений на дома.
20. **Отбойники и ограждения трассы на Ялту** (`cloud/barriers`): металлический отбойник по внешней кромке
    поворотов и над обрывами (по уклону рельефа от кромки), бетонные блоки на мостах; столбики со светоотражателями.
    Инстансами, коллизия для машины.
21. **Трафик** (`cloud/traffic`): машины-боты по полосам главных улиц центра (простые модели, 20–40 шт. вокруг
    игрока), стоят на светофорах из `cloud/traffic-lights`, объезжают игрока; столкновение с игроком — толчок.
22. **Пешеходы** (`cloud/peds`): простые фигуры по тротуарам и паркам центра (30–60 шт. вокруг игрока), отходят
    от машины. Низкополигонально, инстансами.
23. **Заезды на время** (`cloud/races`): 3–5 маршрутов (Севастополь → Ялта, круг по центру, Фиолентовское) с
    чекпоинтами-арками, таймер в HUD, лучшее время в localStorage, меню «Заезды» в паузе.
24. **Леса и посадки вдоль трассы** (`cloud/forest`): `landuse=forest`/`natural=wood` вне центра — деревья
    кластерами с LOD, конус взгляда; не на дорогах. Скорость: ≤ +5%.
25. **Скорость на слабых ноутбуках** (`cloud/lowend`): режим «Низкое» в настройках (меньше теней, дальность,
    разрешение), автопонижение при FPS < 30; замеры до/после в записке.
26. **Вывески и витрины магазинов** (`cloud/signs`): владелец: «город сероватый, скучновато, однотипно». Все точки
    `data/shops.json` (и `sg` у домов) — вывеска над входом на фасаде своего дома (имя из OSM, цвет по типу:
    продукты/аптека/кафе/банк/одежда), подсвеченная ночью; первый этаж под магазином — витрина вместо окон,
    маркиза у кафе. Сети узнаваемыми цветами, где бренд есть в теге (ПУД, ATB, Яблоко, Магнит и т. п.), без
    выдуманных логотипов. Атлас текстур, инстансы, ≤ +5% отрисовки.
27. **Цвет города** (`cloud/colors`): меньше серого — палитра фасадов по типам домов и районам (охра, персик,
    белый инкерманский камень, пастель у хрущёвок), разные крыши, зелень во дворах; без кислотных цветов.
