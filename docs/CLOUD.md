# Работа облачной сессии (Claude Code в вебе)

Облачная сессия — основной исполнитель. Локальная сессия на маке только
проверяет, вливает в `main` и делает то, чего в облаке не сделать
(панорамы Яндекса, прослушивание звука, Blender, если его не поставить).

## Ветки

- Свежая сборка — ветка **`hospital`** на GitHub. Каждую задачу начинай от
  неё: `git fetch origin && git checkout -b cloud/<коротко> origin/hospital`.
- Пушь только свои ветки `cloud/*`. **В `main` не пушить**: пуш в `main` =
  выкладка на сайт; вливает локальная сессия после проверки.
- Одна задача = одна ветка = отдельная записка `docs/handoff/<ветка>.md`
  (что сделано, тронутые чужие файлы и места, как проверить, что осталось) —
  по образцу `docs/HANDOFF.md`.
- `tools/stamp.mjs` не запускать (метки ставит тот, кто вливает). Если всё же
  поменялись `?v=` в импортах — не коммитить эти строки.
- Длинную задачу коммить кусками и пушь по ходу — сессия может оборваться.
- **Сборка волны — твоя.** Готовые задачи сливай сам в ветку `cloud/wave`
  (от свежего `origin/hospital`), конфликты разрешай сам, проверяй, что всё
  вместе запускается (консоль без ошибок, `tools/qa.mjs --quick`), и пушь.
  Локальная сессия вливает только `cloud/wave` — без конфликтов. Строки `?v=`
  в импортах при конфликте бери любые, метки перебьёт штамп.
- Перед каждой новой задачей и перед сборкой волны — `git fetch` и
  `git merge origin/hospital`: туда приходят правки звука и дорог с мака.

## Правила проекта

- Прочитай `README.md`, `docs/NIGHT.md` (устройство, хозяева файлов,
  снимки), `docs/PLAN.md` (весь план). Коммиты и комментарии — на русском, в
  стиле окружающего кода.
- Новое — новым модулем в `web/js/` с минимальной врезкой в `main.js`.
- Звук не трогать (`engine-audio.js`, `carfx.js`, `data/audio/`) — его
  слушает владелец, правки только по его отзыву.
- Ничего не выдумывать про город: только OSM, Викисклад, открытые данные.
  Нет данных — не ставить («лучше пусто, чем криво»).
- Чужие ассеты — только CC0 / CC BY с записью в ATTRIBUTION.
- Скорость: не больше +5% вызовов отрисовки и треугольников на задачу без
  причины. Мерить `G.info`.

## Проверка перед сдачей

- `node tools/qa.mjs --port <порт> --quick --base <прогон до>` — автопроверка
  (кадры, профили дорог, заезды машины); полный прогон без `--quick`.
  Подробно — в шапке `tools/qa.mjs`. Если в облаке нет браузера для
  Playwright — поставь (`npx playwright install chromium`).
- Снимки своих мест «до/после» (`tools/shot.mjs`), каждый открыть и
  посмотреть. В записке — что видно на снимках.

### Мелочи фасадов и кровель — сверх `facades.js` (он покрывает только типовые серии)
