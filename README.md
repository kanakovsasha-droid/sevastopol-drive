# Севастополь — весь город и трасса на Ялту

Браузерная поездка по настоящему Севастополю. Геометрия собрана из открытых
данных, ничего не нарисовано вручную: дороги, дома, зелень и уличные объекты
взяты из OpenStreetMap, рельеф — из спутниковых данных высот.

Карта — **23.8 × 23.3 км** города (Северная сторона, Инкерман, Балаклава,
Камышовая с Казачьей, мыс Херсонес) плюс **коридор Южнобережного шоссе до
Ялты**: полоса ±1500 м вдоль реальной геометрии трассы, ещё пятьдесят
километров дороги. Мир не помещается в память целиком и грузится чанками по
1024 м вокруг игрока — устройство описано в [docs/CHUNKS.md](docs/CHUNKS.md).

Открыть: запустить сервер и зайти на `/web/`.

```bash
python3 tools/serve.py 4180 .
open http://localhost:4180/web/
```

## Что внутри

- **10 201 здание** с контурами из OSM. Этажность у 14% взята из данных,
  остальным оценена по типу и пятну застройки с полем «этажности района»,
  чтобы соседи по кварталу были похожи.
- **Фасады процедурные**: окна, наличники, переплёты, цоколь, карниз, балконы
  и арочные завершения считаются в шейдере по метрам, без единой текстуры.
- **Рельеф** из Terrarium-тайлов. Из него вычтена застройка: SRTM меряет верх
  поверхности, и крыши иначе становятся холмами прямо посреди кварталов.
- **Дороги** с разметкой, тротуарами, бордюрами и зебрами. Полотно кладётся на
  сглаженный профиль, рельеф под ним вдавливается, уклон ограничен 15%.
- **Уличное наполнение** из OSM: 117 остановок с их настоящими названиями на
  табличках, 489 ограждений и подпорных стен, киоски, скамейки, урны, светофоры.
- **Памятные здания** строятся отдельно: отель «Севастополь» с колоннадой и
  буквами на кровле, McDonald's с летней террасой, кедр на кольце Черноморки.

## Как пересобрать данные

```bash
node tools/fetch-osm.mjs        # город и коридор трассы из Overpass
node tools/fetch-terrain.mjs    # тайлы высот, нарезка на чанки
node tools/fetch-poi.mjs        # достопримечательности
node tools/fetch-furniture.mjs  # остановки, скамейки, ограждения
node tools/build-world.mjs      # сборка мира и нарезка на чанки
```

Скачка идёт плитками и продолжается с места обрыва — упавший запрос к Overpass
не заставляет начинать сначала. Быстрый режим для отладки — только прежний
квадрат центра:

```bash
node tools/build-world.mjs --center
```

## Проверки

```bash
node tools/check-terrain.mjs    # рельеф: швы между чанками, дыры в исходнике
node tools/check-route.mjs      # можно ли реально доехать: связность дорог
```

`check-route.mjs` строит граф дорог и ищет путь от площади Нахимова до
Балаклавы, Инкермана, Фороса и Ялты. Карта из плиток разваливается там, где
глазами не видно: дорога обрывается на шве плитки, кусок коридора не доехал.
Ловится это только графом.
