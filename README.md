# Севастополь — центр города, 5 × 5 км

Браузерная поездка по настоящему центру Севастополя. Геометрия города собрана
из открытых данных, ничего не нарисовано вручную: дороги, дома, зелень и
уличные объекты взяты из OpenStreetMap, рельеф — из спутниковых данных высот.

Открыть: запустить сервер и зайти на `/web/`.

```bash
python3 tools/serve.py 4180 .
open http://localhost:4180/web/
```

## Управление

| | |
|---|---|
| `W A S D` | движение |
| `Space` | ручник |
| `Shift` | бег (пешком) |
| `E` | выйти из машины / сесть обратно |
| `C` | режим камеры |
| `M` | меню «куда поехать» |
| `R` | вернуть машину на дорогу |
| `V` | сбросить обзор |
| мышь | обзор, колесо — отдалить |

## Что внутри

- **10 201 здание** с контурами из OSM. Этажность у 14% взята из данных,
  остальным оценена по типу и пятну застройки с полем «этажности района»,
  чтобы соседи по кварталу были похожи.
- **Фасады процедурные**: окна, наличники, переплёты, цоколь, карниз, балконы
  и арочные завершения считаются в шейдере по метрам, без единой текстуры.
- **Рельеф** из Terrarium-тайлов. Из него вычтена застройка: SRTM меряет верх
  поверхности, и крыши иначе становятся холмами прямо посреди кварталов.
- **Дороги** с разметкой, тротуарами, бордюрами и зебрами. Полотно кладётся на
  сглаженный профиль, рельеф под ним вдавливается, уклон ограничен 15%.
- **Уличное наполнение** из OSM: 117 остановок с их настоящими названиями на
  табличках, 489 ограждений и подпорных стен, киоски, скамейки, урны, светофоры.
- **Памятные здания** строятся отдельно: отель «Севастополь» с колоннадой и
  буквами на кровле, McDonald's с летней террасой, кедр на кольце Черноморки.

## Как пересобрать данные

```bash
node tools/fetch-osm.mjs        # город из Overpass
node tools/fetch-terrain.mjs    # тайлы высот
node tools/fetch-poi.mjs        # достопримечательности
node tools/fetch-furniture.mjs  # остановки, скамейки, ограждения
node tools/build-world.mjs      # сборка world.json
```

## Источники

- Дороги, здания, зелень, уличные объекты — [© OpenStreetMap](https://www.openstreetmap.org/copyright),
  лицензия **ODbL**.
- Высоты — тайлы Terrarium (Mapzen / AWS Open Data) на основе SRTM и Copernicus DEM.
- Рендер — [three.js](https://threejs.org), лицензия MIT.
